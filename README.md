**Key Highlights**

* On-device Computer Vision inference
* Real-time gesture recognition

### 👁️ Kritrim Drishti Yantra

An AI-powered wearable assistant for visually impaired individuals.

**Features**

* Captures scene using ESP32-CAM
* Wireless image transmission
* BLIP-based image caption generation
* Converts generated captions into speech
* Real-time environmental awareness assistance

**Tech Stack:** BLIP, Python, ESP32-CAM, Computer Vision, Text-to-Speech
